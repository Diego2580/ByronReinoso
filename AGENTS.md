## Proyectos web existentes

Cuando el usuario solicite mejorar, modernizar, rediseñar o reconstruir una web existente:

1. Inspecciona primero la estructura y tecnologías del proyecto.
2. Identifica las funcionalidades, rutas, integraciones y componentes que deben conservarse.
3. Selecciona únicamente las skills pertinentes.
4. No reconstruyas todo desde cero si una mejora incremental es suficiente.
5. Antes de realizar cambios importantes, presenta un diagnóstico y un plan.
6. Conserva la lógica de negocio y las integraciones existentes, salvo autorización explícita.
7. Trabaja por etapas y evita cambios destructivos.
8. Ejecuta las verificaciones disponibles después de cada etapa.
9. Compara el resultado con los objetivos visuales y funcionales.
10. Documenta los cambios realizados y cualquier limitación de verificación.

El objetivo es mejorar la calidad del proyecto sin perder sus funcionalidades existentes.
