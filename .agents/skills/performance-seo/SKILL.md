# performance-seo

1. Revisa tamaños de imágenes, lazy loading y fuentes.
2. Evita JavaScript y dependencias innecesarias.
3. Verifica título, descripción, encabezados y metadatos pertinentes.
4. Ejecuta Lighthouse si está disponible; reporta métricas medidas, no estimadas.
5. Prioriza cambios por impacto y coste.
