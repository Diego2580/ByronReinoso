# accessibility

1. Revisa HTML semántico, labels y nombres accesibles.
2. Comprueba navegación con teclado, foco y orden lógico.
3. Verifica contraste y alternativas de texto.
4. Considera lectores de pantalla y reducción de movimiento.
5. Distingue pruebas automatizadas de verificaciones manuales; no declares cumplimiento sin evidencia.
