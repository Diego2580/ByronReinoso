## Sistemas visuales premium y experimentales

Adapta el sistema de diseño al posicionamiento y personalidad de cada proyecto.

### Fundamentos

Define o reutiliza:

- Paleta cromática.
- Tipografía y escala de títulos.
- Retícula y espaciado.
- Radios, bordes y superficies.
- Componentes y variantes.
- Estados interactivos.
- Escalas de profundidad y superposición.
- Tokens de movimiento.

### Dirección premium

Cuando el proyecto requiera un lenguaje premium:

1. Prioriza una jerarquía visual fuerte.
2. Utiliza tipografía con intención editorial.
3. Diseña composiciones cuidadas y no repetitivas.
4. Emplea espacios negativos de forma deliberada.
5. Evita efectos decorativos inconsistentes.
6. Mantén coherencia entre páginas.

### Dirección experimental

Cuando el proyecto requiera una experiencia experimental:

1. Permite composiciones asimétricas controladas.
2. Define reglas claras para cambios de escala y profundidad.
3. Crea una gramática consistente de transiciones.
4. Establece qué elementos reaccionan al cursor y al scroll.
5. Evita mezclar estilos de animación incompatibles.
6. Mantén legibilidad y navegación accesible.

### Tokens de movimiento

Cuando corresponda, define valores reutilizables para duración, easing, distancia, escala y opacidad.

No impongas los mismos valores a todos los proyectos.

### Mantenimiento

Respeta el sistema existente cuando sea adecuado.

Antes de introducir nuevos estilos, comprueba si pueden resolverse mediante tokens y componentes existentes.

Evita acumular sobrescrituras globales innecesarias.
