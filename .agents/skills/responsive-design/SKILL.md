# responsive-design

1. Diseña mobile-first y usa contenedores fluidos.
2. Comprueba 375, 768, 1024 y 1440 px si hay navegador disponible.
3. Evita scroll horizontal y controles táctiles diminutos.
4. Ajusta navegación, tipografía, tablas e imágenes.
5. Registra problemas detectados y corregidos.
