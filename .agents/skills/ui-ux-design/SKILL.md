## Dirección de arte y experiencias digitales avanzadas

Cuando el proyecto requiera una experiencia premium, experimental o inmersiva:

1. Analiza el posicionamiento, la audiencia y la propuesta de valor antes de diseñar.
2. Propón una dirección artística propia, evitando patrones genéricos.
3. Define un concepto visual que conecte el diseño con el negocio.
4. Diseña el recorrido de la página como una narrativa visual.
5. Combina composiciones editoriales, tipografía expresiva, imágenes de calidad y espacios bien controlados.
6. Utiliza el contraste, la escala y la profundidad para crear jerarquía.
7. Identifica los momentos donde una interacción sorprendente puede mejorar la experiencia.
8. Mantén visibles las acciones comerciales importantes.
9. Diseña estados hover, focus, loading, empty y error cuando correspondan.
10. Evita que los efectos visuales dificulten la lectura o la navegación.

### Proceso creativo

Antes de implementar un rediseño importante:

- Analiza la identidad existente.
- Propón hasta tres conceptos visuales diferenciados.
- Justifica la dirección recomendada.
- Define un storyboard por secciones.
- Describe el comportamiento del cursor, scroll y transiciones.
- Identifica los componentes necesarios.
- Espera aprobación cuando el usuario haya solicitado una fase de propuesta.

### Criterio de calidad

Una experiencia premium no depende de la cantidad de animaciones, sino de la calidad de su composición, coherencia, ejecución y capacidad para comunicar valor.
