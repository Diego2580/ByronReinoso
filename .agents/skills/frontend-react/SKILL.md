# frontend-react

1. Inspecciona el stack existente antes de modificar dependencias.
2. Crea componentes pequeños, semánticos y reutilizables.
3. Separa datos, presentación y lógica cuando aporte claridad.
4. Incluye estados de carga, error y vacío.
5. Ejecuta build y lint si están disponibles; informa resultados reales.
