# visual-qa

1. Inicia la aplicación y verifica que carga sin errores.
2. Captura móvil y escritorio si hay herramienta de navegador disponible.
3. Revisa alineación, tipografía, recortes, espacios y estados interactivos.
4. Corrige fallos y vuelve a comprobar.
5. Si no hay navegador o capturas, informa claramente que la revisión visual está pendiente.
